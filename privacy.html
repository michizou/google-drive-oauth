Privacy Policy

This application is a personal-use application for accessing Google Drive through rclone and Google OAuth.

Data Access

The application uses Google OAuth to access the user's Google Drive. Data accessed through Google Drive is used only for the user's personal purposes.

Data Sharing

This application does not sell, rent, or share user data with third parties.

Data Storage

This application does not operate a separate server for storing Google Drive data. Files remain in the user's Google Drive and are accessed through authorized OAuth credentials.

Contact

This is a personal-use application. For questions, please contact the application owner through the associated GitHub account.
